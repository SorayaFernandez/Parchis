# Parchís IA · aplicación web

Esta carpeta contiene la aplicación Next.js de Parchís IA. La documentación completa (funcionalidades, arquitectura, variables de entorno, instalación, pruebas y despliegue) está en el [README principal](../README.md).

Comandos habituales, desde esta carpeta:

```bash
npm install
npm run dev     # desarrollo en http://localhost:3000
npm test        # pruebas (Vitest)
npm run lint    # ESLint
npm run build   # compilación de producción
```
